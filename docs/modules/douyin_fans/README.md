# 趣追 / 抖音小程序圈子粉丝任务

这是 Python 原生界面与官方网页的连接模块。默认歌手为封茗囧菌。初始清单根据用户提供的“封茗囧菌的圈子（1095 粉丝）”截图记录，所有初始任务均显示“截图参考 · 未同步”，截图奖励不当作当前平台规则或账号进度。

已默认填入用户提供的官方小程序分享链接，并通过不带账号的 HTTP 请求和隔离 Chromium 实测公开落地页。官方 `RENDER_DATA` 确认名称为**趣追**，标题为**封茗囧菌的圈子**，宿主标记为 `douyinlite`（HostId 2329）。页面只显示“打开小程序”，没有展示任务、进度或签到按钮，因此不声称此链接支持网页自动完成。只接受 HTTPS 的 `douyin.com`、`iesdouyin.com` 及其子域；拒绝外部域名、非 HTTPS、异常端口和聊天页面。短链跳转及实际读取前会再次校验域名。

公开分享页解析得到的入口信息：

- `app_id`: `tte9a89f1576a4b96b01`
- `page_path`: `pages/fandom_detail/index`
- `fandom_id`: `27933289767426`
- `music_aid`: `6797607257627428865`
- `start_page`: `pages/fandom_detail/index?fandom_id=27933289767426&music_aid=6797607257627428865`

这些字段来自官方公开分享页，不是任务 API。解析后仍显示截图任务“未同步”，不会把入口元数据当作任务完成状态。官方页面脚本构造 `microapp` 客户端唤起链接；请在手机抖音或分享页对应宿主中打开趣追完成任务。程序不生成或猜测小程序私有任务接口，也不保存分享者的 Uid、Did 等跟踪字段。

支持的操作：

- 打开专用浏览器登录；按需复用本机已有抖音账号 Cookie 备份。只读账号索引与 Cookie 备份，不读聊天数据库，也不使用聊天标签页。
- 打开圈子、读取可见任务文字与状态，按“真实网页快照”单独标记来源与时间；未识别到的任务明确显示“网页未找到”。
- 仅当页面包含所选歌手、圈子标记和唯一的明确免费签到按钮时，由用户点击原生界面的“尝试免费签到并复查”触发。点击后重新加载官方页面，只有任务行显示已签到才报告成功。
- 评论、分享、投稿、圈子讨论与邀请只提供官方页面手动入口，不替用户提交内容。灯牌、礼物和钻石消费不自动执行。
- 显示官方网页实际 `audio` / `video` 的当前时间、暂停状态与时长。这只是播放器观测值，不等于任务累计时长；不刷播放时长，不伪造平台上报或奖励。

部分圈子任务可能仅客户端开放；遇到客户端专属页、登录墙、未展示任务或无法确认签到结果时，程序会说明需要手动处理，不会把“打开网页”算成任务完成。

数据位于 `data/douyin_fans/`：`config.json`、账号隔离的 `profiles/`、按账号/圈子隔离的 `snapshots/`。圈子 profile 独立于聊天导出与火花，避免同时使用浏览器目录产生锁冲突。请在页面中核对实际登录账号。

服务入口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/douyin-fans/api/state` | 读取本地配置、截图参考和最近快照，不启动浏览器 |
| POST | `/douyin-fans/api/config` | 保存 `artist`、`circle_url`、`account_id` |
| POST | `/douyin-fans/api/login` | 打开专用浏览器供本人登录 |
| POST | `/douyin-fans/api/open` | 打开已配置圈子 |
| POST | `/douyin-fans/api/refresh` | 读取真实网页任务；小程序分享页只解析公开入口 |
| POST | `/douyin-fans/api/resolve` | 不带账号只读解析官方分享页的 app_id / 页面 / 圈子信息 |
| POST | `/douyin-fans/api/checkin` | 尝试免费签到并刷新复查 |
| POST | `/douyin-fans/api/open-task` | 用 `{ "task_id": "comment" }` 打开免费任务手动入口 |

浏览器操作异步执行；POST 返回启动结果，随后通过 GET `state` 的 `running`、`last_result` 和最近快照查看实际结果。`last_result.verified` 只在网页已签到或签到后刷新确认时为真。
