# 抖音火花助手

抖音好友火花自动续期工具，零构建一键启动，基于 Vue 3 + Element Plus + FastAPI 构建，提供扫码登录、好友管理、定时续火花等可视化管理功能。

## 功能特性

### 多账号管理（统一入口）
- **账号只在统一入口维护**：打开 `/douyin` 后点右上角「账号管理」即可登录 / 添加 / 切换 / 重命名 / 删除账号；火花页面不再重复一套账号管理
- **多账号完全隔离**：每个账号独立保存登录态（Cookie）、好友缓存、定时任务、分组数据，
  并拥有独立的浏览器 profile 目录，切换账号即切换整套数据，互不干扰
- **统一登录态**：聊天记录导出和火花共用同一份 Cookie 存档；统一入口切换账号后火花会跟随切换
- **Cookie 自动恢复**：账号保存过 Cookie 后，即使浏览器 profile 登录态失效，
  初始化时会自动用存档 Cookie 恢复登录
- 历史数据自动归属「默认账号」，升级后原有任务、分组、好友缓存无缝保留

### 账户与安全
- 登录状态实时检测
- 上次登录 IP 记录
- 昵称自动识别（**不再抓取本人头像**：为避免多一次主页跳转和误取作品封面，头像位统一用默认图标）
- 管理员密码修改

### 好友管理
- 好友列表展示（头像、火花天数、所属分组）
- **按隐藏 ID 定位好友**：抖音网页端的会话行不显示用户 ID，程序从 React 内部数据里读出
  私聊的 `sec_uid` / 群聊的会话 ID，点击时先按 ID 找人、再校验打开的是不是同一个人。
  同名好友不会点错，好友改了昵称也照样能找到（老任务会记录首次解析到的 ID）
- **一次性加载全部好友**：好友列表是懒加载的，程序会自动逐屏滚动到底把全部好友抓下来（好友多时约 15-20 秒，结果缓存 10 分钟）
- 好友搜索过滤、按分组筛选
- 多选好友后批量创建任务（可选文字 / 表情包 / 文字+表情）或批量加入分组
- 实时刷新好友数据
- **昵称取不到时自动补全**：标题还没渲染就被滚动收走的情况，会在抓完后自动回滚补名；
  实在取不到就先显示「未命名好友（尾号xxxx）」（仍可按隐藏 ID 收发消息），
  好友页会给出提示条和「重新获取昵称」按钮

### 好友分组（核心）
- 新建分组，为分组设置**默认发布时间**和**默认消息内容**
- 分组可配「文字」「表情包」「文字+表情」三种内容：配成表情后，组内好友每天收到同一个表情（可再带一句文字）
- 勾选好友加入分组，一键「应用到任务」为组内所有好友批量创建定时任务
- 修改分组的时间或消息后，再次应用即可同步到组内全部任务
- 一个好友只归属一个分组，加入新组会自动从旧组移出
- 卡片式展示每个分组的同步状态（已同步 / 总人数）

### 聊天与火花详情
- **已并入消息查看器**：统一入口不再有独立的「火花助手」标签；查看器顶部导航可直接进入好友、分组、任务、火花日历和设置
- **聊天页从侧栏隐藏**：聊天记录和火花详情统一在统一入口的「聊天记录」查看器里
- 查看器右侧「火花详情」显示：连续火花天数、今日是否已续、定时任务时间、最近发送记录；会话列表也会标出 🔥 火花天数和 ⏰ 任务时间
- 火花日历 / 任务管理 / 设置可从火花详情面板一键进入
- **查看器内直接发消息**：消息记录底部输入框可直接给当前好友发文字；首次发送会自动初始化火花浏览器，发送成功后把这条消息备份进本地聊天记录
- **初始化不再弹窗**：初始化按钮在会话列表「会话」标题右侧，显示未初始化/初始化中/已就绪；发送消息时也会自动初始化，概览页不再强制弹提示
- 表情包发送仍可从好友列表 →「发送」进入原聊天页
- 所有操作前自动检查并回到 `https://www.douyin.com/chat?isPopup=1`（手动切到视频页/主页也能自动回来）
- 类抖音原生聊天界面（气泡式消息展示）
- 查看好友聊天记录
- 发送文字消息
- 发送表情包：**收藏的表情包 + 自带表情（大表情 / emoji）**都支持，分类 tab 与抖音一致；
  收藏和自带大表情点一下即发送，自带 emoji 自动补一次回车；发送后校验聊天里确实多了一条表情消息
- 左侧好友列表 + 右侧对话窗口的双栏布局
- 发送时输入框上方显示实时阶段（正在打开会话 / 正在输入并发送 / 等待发送确认），
  好友多、需要滚动定位时不会让人以为卡死

### 定时任务
- **发送进度实时可见**：批量执行时显示进度条、当前正在发给谁、已完成 x/y、成功/失败数，
  可随时「停止发送」（当前好友发完即停）；单个「立即执行」也会显示当前阶段
- 为好友创建每日定时发送任务，**支持「文字」「表情包」「文字+表情」三种类型**
  （表情从收藏/自带表情里选；选「文字+表情」会先发文字、间隔约 1 秒再发表情；任务列表显示缩略图）
- 支持自定义消息内容（留空使用全局模板池或每日名言）
- 修改已有任务执行时间
- 删除定时任务
- 任务执行结果与最近消息记录

### 火花日历
- 按月的打卡日历：每天标记续火花的成功 / 失败次数，点某天查看逐条明细（好友、时间、内容或失败原因、来源）
- 顶部统计本月打卡成功次数、有记录天数、覆盖好友数、失败次数，并列出今日计划要发的好友
- 打卡历史长期保存在 `send_history.json`（按账号区分），不占用去重窗口的最近消息记录

### 首页看板
- 浏览器 / 登录状态监测
- 好友数量 / 定时任务数量统计
- 快速操作入口
- 系统运行信息（版本、在线时长、后端地址）

### 设置与风控
- 端口配置、浏览器类型与路径切换
- 浏览器显隐模式切换（**支持无头模式**：自动放大窗口到 1400×900、替换掉
  含 `HeadlessChrome` 的 UA，避免页面按小窗口渲染或缺行）
- 消息模板池自定义
- 定时任务随机延迟（模拟真人）
- 消息去重窗口
- 连续失败自动熔断暂停
- 今日发送次数与最近消息记录

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue 3 (Composition API，全局构建，无构建步骤) |
| UI 组件库 | Element Plus + Element Plus Icons |
| 路由 | Vue Router 4 |
| HTTP 客户端 | Axios |
| 后端框架 | FastAPI + Uvicorn |
| 浏览器自动化 | Selenium（支持 Edge / Chrome / Chromium / Brave） |
| 定时调度 | schedule |

**特点**：前端所有依赖（Vue / Element Plus / Axios）已本地化到 `dist/lib/`，无需 npm install，无需构建步骤，启动后端即可使用。

## 快速开始

### 环境要求

- **Python 3.8+**
- **任一受支持浏览器**：Microsoft Edge（推荐） / Google Chrome / Chromium / Brave
- Windows / Linux

### 安装依赖

```bash
pip install -i https://mirrors.aliyun.com/pypi/simple/ fastapi uvicorn selenium schedule requests
```

> 直连官方 PyPI 容易超时/断连，建议用上面的阿里云镜像。
> 本项目已内置虚拟环境 `.venv`，通常无需重新安装。

### 启动服务

**双击 `启动.bat`** 即可，服务启动后会自动打开管理后台。

- 关闭这个 cmd 窗口 = 停止服务（不会残留后台进程）
- 日志同时写入 `logs/server.log`
- 端口从 `data/config.json` 读取（默认 8080），被占用时自动顺延

也可以命令行启动：

```bash
.venv\Scripts\python.exe 抖音自动续火花-后端.py
```

### Linux 运行说明

- 推荐浏览器：`Google Chrome` 或 `Chromium`
- 若浏览器已加入系统 PATH，可直接在「设置」页选择浏览器类型后保存
- 若浏览器不在默认路径，可在「设置」页填写自定义路径，例如：
  - `/usr/bin/google-chrome`
  - `/usr/bin/chromium`
  - `/snap/bin/chromium`
- Linux 服务器若无桌面环境，建议先开启图形环境或使用虚拟显示；无头模式可用，但稳定性通常不如有头模式
- 无头模式在 Windows / Linux 均可直接使用：设置页把「浏览器显示」关掉并重启后端即可

### 使用流程

1. 双击 `启动.bat`，自动打开管理后台（无需登录）
2. 进入「设置」页确认浏览器类型与显示模式，顺手设好「任务默认值」（默认时间 / 默认消息）
3. 首页点击「初始化浏览器」
4. 点「浏览器登录」弹出浏览器窗口，在窗口里完成抖音登录（自动抓取 Cookie）；
   需要多账号时在设置页「多账号管理」里继续添加，之后点右上角头像即可快速切换
5. 进入「好友分组」页 → 新建分组 → 勾选成员 → 点「应用到任务」
6. 也可在「好友列表」页多选好友，批量创建任务或批量加入分组
7. 在「聊天」页查看聊天记录、发送消息或表情包

## 配置说明

所有配置保存在 `data/config.json`（首次运行自动生成）：

```json
{
  "port": 8080,
  "show_browser": true,
  "browser_name": "edge",
  "browser_path": "",
  "active_account_id": "default",
  "password_hash": "<SHA-256>",
  "task_jitter_minutes": 8,
  "max_consecutive_failures": 3,
  "dedupe_window_days": 7,
  "message_templates": [
    "今天也要开心呀",
    "来给你续一下小火花",
    "保持联系，火花不能断"
  ]
}
```

| 字段 | 说明 |
|------|------|
| `port` | 服务端口，启动时被占用则自动切换 |
| `show_browser` | 是否显示浏览器窗口（有头模式更稳定） |
| `browser_name` | 浏览器类型：`edge` / `chrome` / `chromium` / `brave` |
| `browser_path` | 浏览器可执行文件路径，留空使用系统默认 |
| `active_account_id` | 当前活跃抖音账号 ID（`default` 为默认账号） |
| `password_hash` | 管理员密码 SHA-256 哈希（不存明文） |
| `task_jitter_minutes` | 定时任务触发后的随机延迟分钟数（0~N） |
| `max_consecutive_failures` | 连续失败达到该值后自动暂停所有定时任务 |
| `dedupe_window_days` | 消息去重时间窗，天数内不对同一好友发送相同内容 |
| `default_task_time` | 新建任务 / 新建分组时默认带上的发布时间 |
| `default_message` | 新建任务 / 新建分组时默认带上的消息内容，留空则用模板池 |
| `message_templates` | 全局模板池，留空消息时优先选择未重复内容 |

> 在「设置」页修改端口、浏览器模式或浏览器类型后，**重启后端**生效。

## 防封号措施

为降低封号概率，本工具已内置以下优化：

1. **随机操作间隔**：发送消息、打开聊天、获取表情等操作之间使用随机延迟（1~2.5 秒），模拟真人操作节奏
2. **固定浏览器指纹**：使用本地浏览器用户数据目录持久化会话，避免每次启动都被识别为新设备
3. **降低登录检测频率**：前端 `GetLogin` 状态检查有 30 秒冷却时间，避免频繁请求触发风控
4. **随机延迟执行**：定时任务支持 `0 ~ N` 分钟随机延迟，避免每天固定整点触发
5. **模板池去重**：留空消息时优先从模板池中挑选近期未发过的内容，减少重复文案
6. **自动熔断暂停**：连续失败达到阈值后自动暂停全部任务，避免异常状态下持续触发风控

### 用户操作建议

- 定时任务建议设置在正常作息时段（如 20:00-23:00），避免凌晨自动发送
- 如需自定义消息，建议配置 3 条以上模板并用换行或 `||` 分隔，避免长期固定一句话
- 不要同时登录多个设备操作同一账号
- 保持网络环境稳定，不要频繁切换 IP
- 仅用于续火花，不要频繁手动发送消息

## 常见问题

### 浏览器初始化失败
- **最常见原因：系统代理**。开着公司代理 / VPN / 抓包工具时，驱动与本机浏览器之间的
  localhost 通信会被代理劫持，表现为驱动能启动但所有操作报 `unhandled request`。
  程序已自动把 `localhost` 加入 `NO_PROXY` 规避此问题。
- **第二个原因：驱动版本不匹配**。若 PATH 里有旧版 `msedgedriver.exe`，程序会自动忽略
  版本不符的驱动，改用与浏览器匹配的版本（启动日志会打印一行提示）。
- 初始化后仍失败，可查看 `logs/server.log` 中的具体错误信息。

### 好友加载很慢
- 好友列表是懒加载的，程序需要逐屏滚动到底才能拿全，158 位好友约需 15-20 秒，属正常。
- 抓取结果缓存 10 分钟，期间再次进入页面或切换标签都是秒开。
- 只有点「刷新」按钮才会真正重新抓取。

### 浏览器崩溃 / 会话断开
- 优先使用**有头模式**（设置页「浏览器显示」开关，默认开启）
- Linux 下优先选择 `Chrome` 或 `Chromium`，必要时在设置页填写浏览器可执行文件路径
- 崩溃后前端会提示「浏览器会话已断开」，点击「初始化浏览器」重启即可

### 登录状态不正确
- 点「设置」页的「刷新状态」按钮，会实际检查抖音页面登录状态
- 如需强制设置登录状态，可使用「强制登录」按钮（需输入密码确认，仅调试用）

### 多账号相关
- **切换账号后好友/任务变空是正常的**：每个账号数据独立，新账号需要重新登录并抓取好友列表
- **切换账号会重启浏览器**：切换时自动关闭旧浏览器，用新账号的 profile 目录重新启动，
  原账号的登录态保留在自己的 profile 里，随时可以切回来
- **删除账号会清空其全部本地数据**：Cookie、定时任务、分组、好友缓存和浏览器目录一并删除，
  删除前请确认（默认账号不可删除，只能重命名）
- **Cookie 存档的作用**：浏览器登录成功后 Cookie 会存档到 `data/accounts.json`，
  当 profile 登录态失效（如清理了浏览器数据）时，切换/初始化会自动用存档 Cookie 恢复登录
- **登录等待 10 分钟未完成会自动取消**，重新点击「浏览器登录」即可

### 端口被占用
- 启动时自动检测，若端口被占用会自动切换到下一个可用端口
- 控制台会打印实际使用的端口

### 定时任务丢失
- 定时任务自动持久化到 `data/tasks.json`，重启后端并初始化浏览器后自动恢复

### 自动任务被暂停
- 当连续发送失败达到阈值时，系统会自动暂停所有定时任务
- 可在「设置」页查看失败原因、今日发送次数和最近风险状态
- 处理完异常后，点击「恢复自动任务」即可继续运行

### 表情包发送失败
- 确保已进入聊天页面（先点击好友打开对话）
- 表情包面板需要页面完全加载后才能正常打开，如果失败请稍后重试

## 安全说明

- 密码以 SHA-256 hash 形式存储在 `data/config.json` 中，不保存明文
- 首次启动后请及时在「设置」页修改默认密码 `123456`
- 各账号的抖音登录 Cookie 仅保存在本机 `data/accounts.json`，不与任何服务器同步；
  `data/` 目录已在 `.gitignore` 中排除，不会上传到 Git 仓库
- CORS 仅允许本地来源（localhost / 127.0.0.1）访问
- 「强制登录」调试接口需二次密码确认
- 「浏览器登录」弹出的浏览器使用账号独立的 profile 目录，与日常使用的浏览器互不干扰

## 后端模块架构

```
抖音自动续火花-后端.py  (主入口)
  ├── backend/config.py          配置与常量（含按账号的 profile 目录）
  ├── backend/runtime.py         运行时全局状态（driver/douyin/init/活跃账号/登录等待态）
  ├── backend/utils.py           通用工具
  ├── backend/browser_manager.py 浏览器驱动管理（按账号 + 强制可见启动）
  ├── backend/accounts.py        多账号管理（账号存储、Cookie 存档、切换与清理）
  ├── backend/friends_store.py   好友列表本地缓存（按账号分文件）
  ├── backend/groups.py          好友分组（按账号隔离）
  ├── backend/risk_control.py    风控与消息选择
  ├── backend/auth.py            认证鉴权
  ├── backend/douyin_core.py     Douyin 核心类 → 继承 StickerMixin
  │   ├── 好友管理（列表/搜索/打开对话）
  │   ├── 聊天操作（发送文字/获取历史）
  │   └── 登录初始化
  ├── backend/douyin_sticker.py  StickerMixin → 表情包操作
  │   ├── 打开表情面板
  │   ├── 收集分类表情包
  │   ├── 切换表情 tab
  │   └── 按 src 精准点击表情
  └── backend/scheduler.py       定时任务调度（恢复/保存按活跃账号过滤）
```

多账号相关接口（均经 `/api` 前缀）：`/Api/Account/List`（列表）、
`/Api/Account/Add`（新增）、`/Api/Account/Rename`（重命名）、`/Api/Account/Remove`（删除）、
`/Api/Account/Switch`（切换，重启浏览器并重载该账号数据）、
`/Api/Account/BrowserLogin`（弹出浏览器登录并抓取 Cookie）、
`/Api/Account/LoginState`（轮询登录状态）、`/Api/Account/CancelLogin`（取消登录）。
